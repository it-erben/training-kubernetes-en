# Docker Networking

In dieser Aufgabe legst du ein eigenes Bridge-Netzwerk an und testest es.

- Lege ein Docker Network mit dem Namen `my-bridge` an und starte zwei Container mit Verbindung zum Network.
- Prüfe, ob die beiden Container sich per `ping` erreichen können. Hinweis: Du erreichst einen Container über `ping` mit seinem Namen.
- Trenne einen der Container vom Netzwerk und wiederhole den Test.
- Lösche beide Container und das Netzwerk.
